# Зертханалық жұмыс №10: Виртуализация технологияларын меңгеру (VMware, KVM, VirtualBox)

**Пәні:** DevOps үшін операциялық жүйелер  

---

## 🎯 Мақсаты
* Виртуализация ұғымымен танысу.
* Виртуалды машиналар (ВМ) құру және басқаруды үйрену.
* Әртүрлі виртуализация платформаларымен жұмыс істеу (Oracle VirtualBox, VMware Workstation/Player, KVM).

---

## 🛠 Қажетті құралдар
* **Операциялық жүйе:** Windows / Linux
* **Виртуализация бағдарламалары:** Oracle VirtualBox / VMware Workstation / KVM
* **ISO бейнефайлдары:** Ubuntu / Debian / Windows

---

## 📚 Теориялық бөлім

1. **Виртуализация дегеніміз не?**  
   Виртуализация – бұл бір физикалық компьютерде бірнеше операциялық жүйелерді бір уақытта оқшауланған түрде іске қосуға мүмкіндік беретін технология.
2. **Түрлері:**
   * **Аппараттық виртуализация (Hardware virtualization):** Виртуалды машиналар физикалық машинаның ресурстарын (CPU, RAM, Disk) гипервизор арқылы пайдаланады.
   * **Желілік виртуализация:** Бағдарламалық қамтамасыз ету арқылы виртуалды желілер жасау.
   * **Сақтау виртуализациясы (Storage):** Деректерді сақтау құрылғыларын біріктіру және виртуалдау.
3. **Виртуализация құралдары:**
   * **VirtualBox:** Тегін, кроссплатформалы гипервизор.
   * **VMware Workstation/Player:** Кеңінен қолданылатын коммерциялық өнім.
   * **KVM (Kernel-based Virtual Machine):** Linux ядросына енгізілген ашық кодты виртуализация.

---

## 💻 Тәжірибелік бөлім және есеп

### 🔸 №1-тапсырма: VirtualBox көмегімен виртуалды машина жасау

**Орындалған қадамдар:**
1. Oracle VirtualBox бағдарламасы орнатылды.
2. Жаңа виртуалды машина жасалды:
   * **Қолданылған ISO:** `ubuntu-22.04-desktop-amd64.iso` *(өз ISO файлыңызды жазыңыз)*
   * **Бөлінген RAM:** `2048 МБ` (2 GB)
   * **Диск түрі мен көлемі:** `VDI (динамикалық), 20 GB`
3. ISO бейнефайл тіркеліп, операциялық жүйені орнату процесі жүргізілді.

**Сұрақтарға жауаптар:**
* **Қанша ОЗУ бөлдіңіз?**  
  > *Жауап:* 2048 МБ (2 GB) бөлдім.
* **Виртуализация өтімділігіне (өнімділігіне) қалай әсер етеді?**  
  > *Жауап:* Виртуализация хост-жүйенің (негізгі ПК) ресурстарын (ОЗУ, процессор ядролары, диск) бөлісетіндіктен, ресурстар жеткіліксіз болса негізгі де, виртуалды да жүйенің жұмысы баяулауы мүмкін. Гипервизор қосымша накладные расходы (overhead) тудырады, бірақ заманауи аппараттық қолдау (Intel VT-x / AMD-V) арқасында өнімділік шығыны минималды болады.

### 🔸 №2-тапсырма: VMware Workstation / Player қолдану

**Орындалған қадамдар:**
1. VMware бағдарламасында **"Create a New Virtual Machine"** таңдалды.
2. Қолданылған ОС ISO бейнефайлы көрсетілді.
3. Орнату процесі аяқталып, ВМ ішінен интернетке қосылу тексерілді (Ping орындалды).

* **Қолданылған ОС:** Ubuntu Linux / Windows 10
* **Орнату процесі:** Стандартты орнату шебері (Easy Install) арқылы жүзеге асырылды.
* **Қиындықтар:** Жоқ / Желілік адаптерді (NAT) баптау қажет болды.
